Basic Sales Summary
Project Overview
This project summarizes sales performance using the GlobalSuperstore dataset in Microsoft Excel. It calculates three key performance indicators (KPIs) and verifies the summary.
Dataset
- Dataset: GlobalSuperstore
- Sales column: R (Sales)
- Numeric sales records counted: 51,290
KPIs and Results
KPI	Excel formula	Result
Total Sales	=SUM(GlobalSuperstore!R:R)	12,642,501.91
Average Sales	=AVERAGE(GlobalSuperstore!R:R)	246.490
Transaction Count	=COUNT(GlobalSuperstore!R:R)	51,290


Manual Verification
The summary was checked using:
=ROUND(B5*B6,2)
The result matched Total Sales: 12,642,501.91.
Skills Used
- Excel SUM, AVERAGE, and COUNT functions
- KPI summary creation
- Worksheet formatting
- Manual calculation and validation
Conclusion
The project provides a simple sales performance summary from the GlobalSuperstore dataset. The three KPIs were calculated and the manual verification matched the reported total sales.
